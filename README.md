# Black Card Club — Demo

Demo interactivo del CRM y portal privado de socios premium para un night club en Quito.

**Ver demo:** https://fleremiasflemin20-maker.github.io/crm-nightclub-demo/

- Entra con un clic como Socio, Administración o Portero.
- Todos los datos son ficticios y se guardan solo en tu navegador (botón "Reiniciar" para volver al inicio).
- Este repositorio contiene únicamente la versión compilada del demo; no hay servidor ni datos reales.
